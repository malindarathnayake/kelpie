---
title: CLI reference
description: Kelpie commands for sessions, workspaces, tabs, panes, agents, waits, integrations, and status.
---

Kelpie’s CLI talks to the running server over the same local socket API used by integrations and agents.

Most commands print JSON responses. Use them from scripts when you want deterministic automation.

## Launch and status

```bash
kelpie                         # launch or attach to the default session
kelpie --session work          # launch or attach to a named session
kelpie --remote workbox        # attach through SSH, using local keybindings
kelpie --remote workbox --remote-keybindings server
kelpie --no-session            # single-process escape hatch
kelpie --default-config        # print default config
kelpie update                  # download and install the latest version
kelpie --version               # print version
```

Status commands:

```bash
kelpie status
kelpie status server
kelpie status client
```

## Server

```bash
kelpie server
kelpie server stop
kelpie server reload-config
```

`kelpie server` runs the headless server explicitly. Use it for supervised or service-style setups. `reload-config` applies reloadable settings without restarting panes.

## Sessions

```bash
kelpie session list [--json]
kelpie session attach <name>
kelpie session stop <name> [--json]
kelpie session delete <name> [--json]
```

Use `default` as the session name when you need to stop the default session explicitly.

## Workspaces

```bash
kelpie workspace list
kelpie workspace create [--cwd PATH] [--label TEXT] [--focus] [--no-focus]
kelpie workspace get <workspace_id>
kelpie workspace focus <workspace_id>
kelpie workspace rename <workspace_id> <label>
kelpie workspace close <workspace_id>
```

Create a workspace without stealing focus:

```bash
kelpie workspace create --cwd ~/project --label api --no-focus
```

## Worktrees

```bash
kelpie worktree list [--workspace ID | --cwd PATH] [--json]
kelpie worktree create [--workspace ID | --cwd PATH] [--branch NAME] [--base REF] [--path PATH] [--label TEXT] [--focus] [--no-focus] [--json]
kelpie worktree open [--workspace ID | --cwd PATH] (--path PATH | --branch NAME) [--label TEXT] [--focus] [--no-focus] [--json]
kelpie worktree remove --workspace ID [--force] [--json]
```

Worktrees are normal Kelpie workspaces with Git checkout provenance. `worktree create` creates a Git worktree checkout, opens it as a workspace, and groups it with the parent repo workspace. Without `--path`, Kelpie creates the checkout under `<worktrees.directory>/<repo>/<branch-slug>`.

`workspace close` closes Kelpie state only. `worktree remove` is the explicit checkout deletion path; it runs `git worktree remove`, never deletes the branch, and requires `--force` when Git refuses a dirty checkout.

## Tabs

```bash
kelpie tab list [--workspace <workspace_id>]
kelpie tab create [--workspace <workspace_id>] [--cwd PATH] [--label TEXT] [--focus] [--no-focus]
kelpie tab get <tab_id>
kelpie tab focus <tab_id>
kelpie tab rename <tab_id> <label>
kelpie tab close <tab_id>
```

## Panes

```bash
kelpie pane list [--workspace <workspace_id>]
kelpie pane get <pane_id>
kelpie pane rename <pane_id> <label>|--clear
kelpie pane split <pane_id> --direction right|down [--cwd PATH] [--focus] [--no-focus]
kelpie pane close <pane_id>
```

Read output:

```bash
kelpie pane read <pane_id> [--source visible|recent|recent-unwrapped] [--lines N]
kelpie pane read <pane_id> --source visible --ansi
kelpie pane read <pane_id> --source recent-unwrapped --lines 120
```

Send input:

```bash
kelpie pane send-text <pane_id> <text>
kelpie pane send-keys <pane_id> <key> [key ...]
kelpie pane run <pane_id> <command>
```

`pane run` submits text plus Enter atomically. Prefer it over `send-text` plus `send-keys Enter` for commands.

Report agent state from custom hooks:

```bash
kelpie pane report-agent <pane_id> \
  --source ID \
  --agent LABEL \
  --state idle|working|blocked|unknown \
  [--message TEXT] \
  [--custom-status TEXT] \
  [--seq N]
```

## Agents

```bash
kelpie agent list
kelpie agent get <target>
kelpie agent read <target> [--source visible|recent|recent-unwrapped] [--lines N] [--format text|ansi] [--ansi]
kelpie agent send <target> <text>
kelpie agent rename <target> <name>|--clear
kelpie agent focus <target>
kelpie agent wait <target> --status <idle|working|blocked|unknown> [--timeout MS]
kelpie agent attach <target> [--takeover]
kelpie agent start <name> [--cwd PATH] [--workspace ID] [--tab ID] [--split right|down] [--focus|--no-focus] -- <argv...>
```

Agent targets can be terminal IDs, unique agent names, detected or reported agent labels, or legacy pane IDs. Names and labels are agent identities. Terminal IDs and legacy pane IDs are low-level escape hatches.

`agent read` reads the resolved terminal stream. `agent send` writes literal text to that stream. `agent get`, `agent focus`, `agent wait`, and `agent attach` require the resolved terminal to have agent identity. `agent rename` can assign that identity.

Use `pane send-text`, `pane send-keys`, `pane run`, and `terminal attach` for ordinary terminals, servers, tests, shells, or low-level terminal control. Use `pane run` when you want to submit a command with Enter.

## Direct terminal attach

```bash
kelpie terminal attach <terminal_id> [--takeover]
```

Detach from direct attach with `ctrl+b q`. Send literal `ctrl+b` with `ctrl+b ctrl+b`.

## Waits

Wait for output in a pane:

```bash
kelpie wait output <pane_id> --match <text> [--source visible|recent|recent-unwrapped] [--lines N] [--timeout MS] [--regex] [--raw]
```

Wait for pane agent state:

```bash
kelpie wait agent-status <pane_id> --status <idle|working|blocked|done|unknown> [--timeout MS]
```

Use `wait output` for normal commands and servers. Use `wait agent-status` for coding agents.


## Read sources

| Source | Meaning |
| --- | --- |
| `visible` | Current rendered screen. Best for UI feedback loops. |
| `recent` | Recent scrollback with terminal wrapping. |
| `recent-unwrapped` | Recent scrollback without soft wrapping. Best for logs. |

## Environment variables

| Variable | Purpose |
| --- | --- |
| `KELPIE_CONFIG_PATH` | Override the config file path. |
| `KELPIE_SESSION` | Select a named session for CLI commands. |
| `KELPIE_SOCKET_PATH` | Low-level socket path override. |
| `KELPIE_LOG` | Set log filter, for example `KELPIE_LOG=kelpie=debug`. |
| `KELPIE_DISABLE_SOUND` | Disable sound playback even when sound notifications are enabled. |
