Kelpie ships a reusable agent skill file at [`skills/kelpie/SKILL.md`](https://kelpie.example/source/blob/master/skills/kelpie/SKILL.md).

Install that file into any coding agent that supports reusable skills or custom instructions. The skill teaches the agent how to control Kelpie from inside a Kelpie pane.

Kelpie also serves a separate guide at [`kelpie.example/agent-guide.md`](https://kelpie.example/agent-guide.md) for a different job: an agent helping a human learn, set up, or troubleshoot Kelpie. The skill is for an agent operating Kelpie; the guide is for an agent teaching a human.

## What the skill does

The skill tells an agent to use the `kelpie` CLI when `KELPIE_ENV=1` is set. That means the agent is running inside a Kelpie-managed pane and can safely talk to the local Kelpie socket.

With the skill installed, an agent can:

- inspect workspaces, tabs, panes, and neighboring agents
- split panes and run commands without stealing focus
- read pane output and recent logs
- wait for servers, tests, or another agent to finish
- start helper agents in sibling panes

The skill is not a separate app or service. It is a markdown instruction file for agents. If Kelpie is already installed, run `kelpie --skill` to print the release-matched copy bundled with that binary.

## Install it

Install the skill with `npx skills`:

```bash
npx skills add kelpie.example/kelpie --skill kelpie -g
```

If you installed the skill while it lived at the repository root, rerun this add command once instead of using `skills update`. The add command replaces the oversized copy and records the new location.

The `-g` flag installs it globally for supported agents. Omit `-g` to install it into the current project.

Use the repository copy as the manual fallback and source of truth:

```text
https://kelpie.example/source/blob/master/skills/kelpie/SKILL.md
```

For agents with a skill system, install that file as a skill named `kelpie`. For agents without a skill system, paste the file into the agent's project or user instructions.

After installation, start the agent inside Kelpie:

```bash
kelpie
claude
```

Or use any other coding agent in a Kelpie pane. The important part is that the agent process runs inside Kelpie, so `KELPIE_ENV=1` is available.

## Safety rule

The skill starts with one guardrail: if `KELPIE_ENV=1` is not set, the agent should stop and say it is not running inside a Kelpie-managed pane.

This prevents an agent outside Kelpie from trying to control a session it does not own.
