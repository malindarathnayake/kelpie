---
title: Concepts
description: Understand Kelpie workspaces, tabs, panes, agents, sessions, and modes.
---

Kelpie is a terminal workspace manager. It keeps real terminal processes running and adds structure around them.

## Workspace

A workspace is the top-level project container. Use one workspace per repo, task, or investigation.

A workspace owns tabs and panes. Its sidebar state rolls up from the agents inside it, so you can see which project needs attention.

## Tab

A tab is a layout inside a workspace. Use tabs to separate views like `agents`, `logs`, `server`, or `review`.

Tabs are addressable from the CLI and socket API.

## Pane

A pane is a real terminal. Kelpie renders the terminal output, sends input back to the process, and preserves the pane across client detach.

Panes can be split right or down. They can be renamed manually, read from the CLI, sent input, and closed.

## Agent

An agent is a process Kelpie recognizes inside a pane. Kelpie detects agents from foreground processes, screen heuristics, and optional integrations.

Agent states are:

| State | Meaning |
| --- | --- |
| `blocked` | The agent needs input, approval, or a decision. |
| `working` | The agent is actively running. |
| `done` | The agent finished and you have not looked at it yet. |
| `idle` | The agent is finished or waiting and has been seen. |
| `unknown` | Kelpie cannot confidently classify the state. |

## Session

A session is a persistent Kelpie server namespace. The default `kelpie` command attaches to the default session.

Named sessions are separate runtime namespaces:

```bash
kelpie session list
kelpie session attach work
kelpie session attach side-project
```

Use workspaces first. Use named sessions when you need completely separate panes, sockets, and persisted runtime state.

## Client and server

By default, Kelpie runs as a background server plus one or more attached clients.

The server owns panes and process state. The client is the terminal UI attached to that server.

Detach the client with `ctrl+b q`. The server and agents continue running.

Stop the server when you are done:

```bash
kelpie server stop
```

## Modes

Kelpie has terminal mode and navigate mode.

Terminal mode sends keys to the focused pane. Navigate mode sends keys to Kelpie.

Press the prefix key, default `ctrl+b`, to enter navigate mode. Use navigate mode to create workspaces, split panes, switch tabs, resize, open menus, or detach.

## Mouse UI

Kelpie is mouse-native. You can click panes, tabs, workspaces, and agents. You can drag split borders, select text, and use right-click menus.

If you prefer keyboard-only control, or you want Kelpie to stop capturing mouse input, disable mouse capture:

```toml
[ui]
mouse_capture = false
```
